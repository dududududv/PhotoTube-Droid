# UI 子树开发指令

- 修改视觉尺寸前，先阅读 `@../../../../../../../../docs/design/README.md`。
- 功能页面放在对应命名包中，共享页面框架放在 `components/`。
- 禁止在 Composable 中创建全局仓库数据。
- 系统安全区只能在明确的页面边界应用一次，避免重复叠加状态栏或导航栏内边距。
- 保持 `24dp` 主边距、`4dp` 图片缝隙以及不小于 `48dp` 的触控区域。
- 浅色悬浮组件必须复用 `android16Glass`；不得退回不感知背景的纯白或半透明色块。
- 直接使用 API 36，不得在 UI 子树中加入旧 Android 版本判断。
- 新增页面时，必须在架构文档中说明状态所有者和返回行为。
- 布局变更后必须构建调试 APK，并执行视觉验收矩阵。
