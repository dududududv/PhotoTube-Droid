# ADR 0001：Mock 图片采用离线打包

- 状态：已采纳
- 日期：2026-08-30

## 背景

原型包含大量图片，并需要稳定进行像素级验收。随机远程图片可能改变裁切结果、首次启动加载失败，还会在产品媒体层尚未设计时提前引入网络权限和图片加载依赖。

## 决策

把一组确定性的示例图片打包进 `drawable-nodpi`，最终响应式裁切交给 Compose 的 `ContentScale.Crop`。

## 影响

- Demo 和截图验收可以离线运行，结果保持确定。
- APK 体积会大于纯远程 URL Mock。
- 生产级媒体加载应在后续独立设计，并替换 Mock 数据仓库，而不是继续扩展当前静态方案。
