# ADR 0002：Mock 阶段采用轻量导航

- 状态：已采纳
- 日期：2026-08-30

## 背景

当前只有两个视觉页面，并且不需要正式的业务参数。此时引入 Navigation Compose 会新增依赖与路由契约，但没有真实后端流程可以验证这些设计。

## 决策

在 `PhotoTubeApp` 中通过 `rememberSaveable` 保存页面枚举。点击合集进入照片时间线；返回键与合集入口返回合集概览。

## 影响

- Mock 代码保持轻量，且页面状态可以跨 Activity 重建保存。
- 暂不支持深链、独立返回栈和类型安全的合集参数。
- 当实现第三个功能页面或外部入口时，用正式导航图替换当前状态枚举。
