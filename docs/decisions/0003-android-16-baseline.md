# ADR 0003：Android 16 作为唯一平台基线

- 状态：已采纳
- 日期：2026-08-30

## 背景

产品处于从零开始的视觉与架构阶段，没有旧设备用户或历史安装包需要兼容。兼顾旧系统会迫使图形、窗口和交互实现保留多套路径，降低 UI 一致性并增加测试矩阵。

## 决策

将 Android 16（API 36）设为项目唯一平台基线，`minSdk`、`targetSdk` 和 `compileSdk` 均为 36。代码可以直接使用 API 36 能力，不增加旧版本判断或降级实现。

首个专属实现是硬件背景毛玻璃：页面用 `hazeSource` 捕获 Compose 图层，悬浮组件通过 `hazeEffect` 在自身坐标采样背景，并由 Android `RenderEffect` 执行空间模糊。白色雾化、颗粒和高光边缘在模糊结果上继续合成。

## 影响

- UI 可以围绕 Android 16 图形与窗口模型统一设计。
- API 35 及以下设备无法安装应用。
- 每项专属 API 都必须在 API 36 设备或模拟器上执行运行时验证，单纯编译通过不视为完成。
- 如果未来改变最低版本，必须新增 ADR，并逐项设计明确的降级路径。
