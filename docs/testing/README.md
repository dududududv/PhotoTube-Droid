## 功能冒烟测试

### 连接与认证

1. 清除应用数据后启动：显示服务地址配置页，不直接进入 Mock 时间线。
2. 输入无效地址或带额外路径的地址：停留在配置页并显示原因。
3. 输入可用 PhotoTube 地址：先验证 health，再按 session 状态进入登录、初始化提示或内容页。
4. 输入错误口令：表单显示 `INVALID_CREDENTIALS` 文案，不发生循环跳转。
5. 登录成功后杀进程重启：加密 Cookie 恢复，会话有效时直接进入内容页；恢复后仍只在原 host、匹配 path 和 HTTPS 要求满足时携带。
6. 让服务端会话失效并由图片、视频和 API 并发触发 `UNAUTHORIZED`：回登录页且本地会话边界只清理一次；即使失效前发出的 `/auth/session` 随后返回已认证，也不能恢复内容页。
7. 切换或直接连接另一个服务器：在新地址 health/session 探测前清除旧 Cookie 与认证媒体缓存，不能把旧主机 Cookie 发送到新地址。
8. 服务端返回带 `logId` 的结构化错误：错误正文可选择，并显示“复制日志 ID”；复制结果只包含该 ID，不包含 Cookie、口令或完整请求。

### 账号、退出与切换服务器

1. 从照片库菜单进入“账号与服务器”：显示 `/auth/session` 返回的显示名、用户名和当前规范化服务器地址，不显示 Cookie 或 token。
2. 点击退出或切换：操作前均出现二次确认，文案分别说明服务端会话、本机 Cookie、三层媒体缓存、服务器地址和 NAS 原文件边界。
3. 确认退出：只发送一次 `POST /api/v1/auth/logout`；收到 `204` 后回登录页，服务器地址保留，Cookie、Coil 内存、Coil 磁盘和 OkHttp 缓存均清空。
4. 让登出返回 `500`：停留在认证内容和账号页，显示结构化错误与日志编号；本地 Cookie 不清除，用户可以重试，界面不得声称已退出。
5. 确认切换且旧服务器正常：先请求登出，再进入服务器配置页；旧地址、Cookie 与三层媒体缓存全部清除。
6. 确认切换且旧服务器离线或返回 `500`：仍进入服务器配置页并清除本地边界，同时显示“旧服务器没有确认登出”，不得无提示吞掉风险。
7. 切换到另一个主机后抓包：任何请求都不能携带旧主机的 `phototube_session`；旧服务器的缓存照片不得离线闪现。
8. 上述操作不得产生资产、相册、任务或 NAS 写请求；网络中不出现 AI、标题、描述、GPS 或拍摄时间编辑端点。

### 现有视觉流程

1. 完成服务器连接与登录后：远端照片开始加载，底栏悬浮在系统导航区上方。
2. 首屏加载显示进度；无资产显示空状态；失败显示结构化错误与可用的日志编号。
3. 滚动到接近底部：自动请求下一页，加载期间不清空已显示资产。
4. 让下一页 cursor 在服务端失效：列表应从首页重新建立，不能把 cursor 当页码递增。
5. `PROCESSING` 资产显示占位，视频显示类型标识，缺失 `contentHash` 时不请求缩略图。
6. 点击头像或底部“图集”：进入合集概览；点击合集卡片回到远端时间线。
7. 旋转设备或重建 Activity：当前页面状态保持不变，Paging 数据由 ViewModel 缓存。
8. 把底部玻璃导航滚动到照片上方：玻璃能吸收照片色相并明显雾化细节，图标保持锐利。
9. 点击“照片 / 图集 / 创作”，或在中间长胶囊上水平拖动：白色椭圆滑块应平滑移动，三项均进入对应真实页面。
10. 检查底栏左右圆形动作按钮：它们与中间导航保持清楚间隙，不出现相互粘连、边框或方形点击反馈。
11. 切换“年 / 月 / 日”：白色椭圆滑块平滑移动，摘要请求分别携带 `YEAR/MONTH/DAY`，旧请求晚到不覆盖新选择。
12. 日视图第一个七张组：行节奏为 `2 + 3 + 2`，首行主图宽度约为次图 `1.72` 倍，后两行为三等分与双等分。
13. 用不同 offset 但接近 UTC 日界的资产验收：分组必须保留 `takenAt` 原 offset 对应的日期，不得被手机时区改到前一天或后一天。

### 时间线高级筛选

1. 点击顶部筛选：打开面板但不立即刷新时间线；关闭面板后原筛选和当前 Paging 内容保持不变。
2. 组合照片/视频、收藏三态、精确星级：点击“应用”后 `/assets` 与当前粒度 `/assets/timeline-summary` 携带完全相同的参数并从首页重新加载。
3. 选择开始日和结束日：请求边界覆盖设备当前时区下首日全天到末日全天；开始日晚于结束日时显示本地错误且不发请求。
4. 逐层进入媒体库和目录：只请求 `/folders?libraryId=<uuid>&path=<relative>`；界面和日志不出现 NAS 宿主机绝对路径。
5. 指定目录后：返回结果包含该目录和全部后代；切换媒体库或路径不复用上一层 cursor，离线媒体库不可选择。
6. 为不同标签分别选择“全部包含 / 任一包含 / 排除”：请求发送排序稳定的 `tagsAll/tagsAny/tagsExclude` CSV，同一标签不能同时落入多组。
7. 更换标签搜索词或加载下一页：已选条件仍显示在面板顶部且可单独移除；大于 `2147483647` 的标签 ID 不溢出。
8. 应用后顶部显示激活标记和条件维度数；点击“清除”恢复 `archived=false&private=false` 的默认时间线。

### 资产查看、收藏与标签

1. 点击照片：先看到 MD 占位，随后显示 `/original`；双指缩放范围为 1–3 倍。
2. 点击视频：Media3 控制条可播放和拖动；服务端应观察到 206 Range。拖到边界返回 416 时显示“从头重试”，点击后从位置 0 重新准备，不崩溃也不自动循环。
3. 打开 `PROCESSING` 资产：只可能请求版本化 MD 缩略图，不请求 `/original` 或 `/motion-video`；打开 `DISCOVERED`、`FAILED`、`OFFLINE`、`TRASHED` 资产只显示对应状态，不循环请求不可用媒体。
4. 收藏和取消收藏：请求发送明确目标值，返回时间线后列表与摘要刷新。
5. 模拟收藏 HTTP 200 但 `failed` 非空：详情显示逐项失败文案，不错误点亮收藏。
6. 打开标签面板：可搜索、加载下一游标页、添加已有标签、创建并添加新标签、移除标签。
7. 使用大于 `2147483647` 的标签 ID：操作仍成功，不发生 Int 溢出。
8. 让会话过期或切换服务器：详情退出，之前的受保护图片不再从内存或磁盘缓存显示。
9. 点击“照片信息”：按内容、拍摄、文件和 PhotoTube 分组显示，不出现标题、描述、GPS 或拍摄时间编辑控件。
10. 打开带 `+08:00` 拍摄时间的跨时区资产：面板仍显示原响应墙上时间和 `+08:00`，不换算为手机当前时区。
11. 分别打开六种资产状态：信息面板始终可读；哈希为空时显示“尚未计算”，离线或回收站不尝试读取原文件。
12. 长按相对路径、内容哈希、媒体库 ID 和资产 ID：系统文本选择可用，路径仍不包含 NAS 宿主机绝对根目录。
13. 让缩略图或编辑渲染先返回 `503 + Retry-After: 1` 再成功：同一安全 GET 等待后恢复显示；连续挂起最多额外重试两次，单次等待最多 5 秒。
14. 对原图、视频、首页或任意写请求返回同样响应：PhotoTube 自定义重试层不得重放；`Retry-After: 0` 也不得与 OkHttp 的一次内建立即重放叠加。
15. 从搜索结果进入查看器并收藏，返回后搜索、时间线摘要和首页均刷新；标签库 revision 不应因收藏变化。
16. 在同一查看器连续修改评分、标签和编辑版本后退出：各消费者只需换代一次，标签列表计数和智能相册也刷新。
17. 设为私密、移入/恢复/清除回收站：普通列表、私密列表、相册、搜索、重复项和首页均不保留旧成员；回收站三类操作换代全部资产消费者。

### 人工标签库管理

1. 从照片库菜单进入标签管理：首屏请求 `GET /tags?limit=100`，结果按使用数倒序、ID 升序；加载下一页只原样回传 cursor。
2. 搜索包含空格或 emoji 的关键词：按输入字面值发送，最多 120 个 Unicode code point；更换查询后旧 cursor 不得继续使用。
3. 连续两次提交同一关键词：两次都建立新的 Paging generation 并重新请求首页，不因 `StateFlow` 值相同而吞掉显式刷新。
4. 新建标签：POST 只发送去除首尾空白后的 `{name}`，成功后列表刷新；重名冲突显示服务端结构化错误。
5. 提交创建、重命名或删除后立即离开页面：服务端成功事件应保留，重新进入时恰好消费一次并刷新标签列表及根级消费者。
6. 重命名大于 `2147483647` 的标签 ID：PATCH 路径保留 Long，body 只有 `{name}`；资产关系和当前筛选 ID 保持不变，名称候选刷新。若响应携带其它 ID，显示契约错误，不显示成功反馈，也不失效错误标签。
7. 删除标签前必须二次确认，文案明确将移除全部资产关系但不删除照片或 NAS 文件；DELETE 无请求体并显示响应中的 `affectedAssetCount`。
8. 删除一个正用于 AND/OR/NOT 条件的标签：该 ID 从三组草稿与已应用筛选中移除，其余筛选条件保持不变，列表和摘要使用新条件重建。
9. 删除或重命名后重新打开同一照片：资产详情不得继续显示旧标签；归档、私密、回收站、搜索、智能图集与首页在再次显示时刷新。
10. AI worker 关闭时上述流程仍完整可用，网络中不出现 `/tag-scans`、`/tag-rules` 或 `/system/ai-settings`。

### 非破坏性图片编辑

1. 打开带 64 位哈希的 `BROWSABLE` JPEG/PNG：资产操作出现“非破坏性编辑”；视频、GIF、WebP、RAW、无哈希或非可浏览资产不出现入口。
2. 调整左右/上下裁剪、顺时针旋转和双轴镜像：预览与裁剪框同步更新，裁剪任一边不得缩到 1% 以下。
3. 有草稿时退出或选择历史版本：必须先确认放弃；取消确认后草稿保持不变。
4. 保存新版本：请求包含完整 transform、当前 `contentHash` 和预期激活版本；成功后该版本立即激活，NAS 原文件哈希和字节数不变。
5. 切回原图：PATCH 的 `targetEditVersionId` 明确为 `null`，历史仍存在；重新激活 CURRENT 历史后网格和查看器显示编辑渲染。
6. 服务端返回 `STALE` 历史：条目显示“原图已变化”且不可点击，查看器回退 `/original`。
7. 另一客户端先保存或切换版本：本端请求收到 `409` 后刷新资产与历史，不覆盖对方版本，并提示并发状态已变化。
8. 编辑 render 为 `PENDING`：历史显示“生成中”，应用不崩溃；渲染就绪后重新进入可显示 PREVIEW。

### 基础搜索

1. 点击照片页顶部搜索：进入独立搜索页并自动聚焦输入框。
2. 输入少于 3 个去空字符：显示本地校验，网络不得发起 `/assets` 或摘要请求。
3. 搜索 `Coast_100%`：服务端按文件名字面子串匹配，`_` 和 `%` 不得被客户端转成通配查询。
4. 组合照片/视频、收藏和精确星级后搜索：列表与 `/assets/timeline-summary?granularity=DAY` 携带完全一致的筛选参数。
5. 连续快速提交两次查询：旧摘要请求取消，旧响应不得覆盖新查询的计数。
6. 搜索结果固定排除私密与已归档资产；空结果显示明确空态，追加页失败不清空已有结果。
7. 从结果打开资产并返回：保留已提交查询，资产变更后刷新当前结果。
8. 输入 2 个 emoji：按 2 个 Unicode code point 判定为不足；输入 255 个 emoji 完整保留，继续输入不会出现孤立代理项或乱码。
9. 相同关键词和筛选连续提交两次：第二次仍建立新的 Paging generation；第一次摘要晚到不得写回。摘要加载中改成不足 3 个字符并提交时，列表清空且“正在统计”立即结束。

### 手写游标分页恢复

1. 在单图标签候选加载下一页时返回 `INVALID_CURSOR`：旧候选被丢弃并按当前关键词从第一页重载，不显示半新半旧集合。
2. 编辑器为查找当前激活版本跨页时返回 `INVALID_CURSOR`：丢弃已累积历史并从第一页重建，当前版本仍按新 generation 定位。
3. 路径相册读取完整路径集合的深页游标失效：重新请求第一页且最终结果不包含旧 generation 的路径。
4. 对同一流程连续两次返回 `INVALID_CURSOR`：只允许一次自动重建，第二次显示服务端错误与 `logId`，不得形成请求循环。
5. 服务端返回与请求相同的 `nextCursor`：停止追加并暴露契约错误；单图标签、编辑历史和路径集合都不得无限重复加载同一页。

### 协程取消与过期请求

1. 在服务器连接、登录或 bootstrap 尚未返回时销毁页面作用域：取消不得被映射成连接错误，也不得恢复认证内容。
2. 在退出或切换服务器请求执行期间销毁根作用域：不得因 `CancellationException` 写入“服务器切换失败”或跳转到新的错误阶段。
3. 在私密解锁、锁定或 session 探测期间离开私密页、重复项或 XMP：旧页面不得出现口令错误、重新授予私密范围或恢复分页。
4. 在资产详情加载、收藏、评分、归档、私密、标签或编辑 mutation 期间关闭查看器：取消不生成错误卡，也不向新资产状态写回结果。
5. 在图集创建、路径浏览或任务控制期间销毁对应 ViewModel：取消保持为控制流，不增加刷新 revision 或成功提示；销毁认证内容根级回收站 ViewModel 时同样不得把取消映射为失败或发送成功事件。

### 资产异步请求隔离

1. 打开资产 A 并延迟详情响应，随后打开资产 B：A 的成功或失败响应不得替换 B、关闭 B 的加载态或显示 A 的错误。
2. 对 A 发起收藏、评分、归档、回收站或私密 mutation 后切到 B：请求路径仍必须是 A，晚到结果不得改变 B 的字段、关闭 B 或累计到 B 的变更集合。
3. 在 A 的标签新增、创建并添加或移除请求挂起时切到 B：服务端 mutation 目标保持 A；返回后不得改写 B 的标签，也不得用 A 的候选或错误覆盖 B。
4. A 因 `PRIVATE_ACCESS_REQUIRED` 显示口令框后开始解锁，随后关闭口令框或切到 B：解锁回调不得重新打开旧弹窗、刷新 B 或对 B 调用 A 的私密目标状态。
5. A 的编辑保存、版本切换或 `409` 刷新尚未完成时打开 B：编辑 ViewModel 丢弃 A 的晚到 UI 结果；`EditApplyEvent.assetId` 不等于当前 assetId 时查看器只消费事件、不应用摘要。
6. 同一资产 revision 换代：旧 generation 的标签、详情和 mutation 回调不得覆盖新 revision；新的正常请求仍可更新状态。

### 首页概览

1. 在照片页点击底栏左侧布局按钮：请求一次 `/home`，并在不改变底部“照片”激活项的前提下切换为概览。
2. `onThisDay=[]`：不渲染“往年今日”标题或空卡；其它非空区块仍正常显示。
3. 五个区块均为空：显示唯一的首页总空态，不对各区块分别堆叠空态。
4. 点击往年今日、最近拍摄或最近入库资产：打开同一资产查看器；返回后仍处于首页概览。
5. 点击常用图集：打开图集详情；返回或删除后回到照片首页，而不是图集列表。
6. 点击任务摘要：进入任务中心；`total=null` 继续显示“已发现 N 个”，不计算假百分比。
7. 再次点击底栏左侧布局按钮：返回时间线，已加载 Paging 和年/月/日选择不被重置。
8. 初始 `/home` 尚未返回时触发收藏、评分、标签、归档、私密、编辑或回收站失效：必须立即发起新的 `/home`；旧请求即使忽略取消并最后返回，也不得覆盖最新首页或错误状态。
9. 在相同筛选和相同年/月/日粒度下触发两次根级刷新：第二次必须建立新摘要 generation；第一次响应即使不响应取消并最后返回，也不得覆盖第二次计数、加载态或错误。

### 创作入口

1. 从照片或图集页点击底部“创作”：请求 `/assets?kind=PHOTO&archived=false&private=false&limit=100`，不请求视频、私密、归档、AI、上传或元数据写端点。
2. 切换“仅显示收藏”：建立新的 Paging generation，并额外发送 `favorite=true`；再次切换恢复全部普通照片，不复用收藏 cursor。
3. 点击左侧布局按钮：网格只在 2 列和 3 列间切换，已加载照片身份和服务端顺序不变。
4. `BROWSABLE` 且带合法哈希的 JPG/JPEG/PNG 显示“可编辑”；处理中、离线或其它格式显示诚实状态，仍可进入统一查看器但没有伪编辑入口。
5. 点击可编辑照片：进入资产查看器，打开编辑器保存新版本后返回创作页；列表使用新的内容版本缩略图，NAS 原文件字节不变。
6. 从创作页打开搜索再返回：回到创作页而不是照片时间线；从搜索结果打开资产、再返回搜索和创作的层级保持不变。
7. 从创作进入私密资产查看器的防御验证：即使服务端异常返回私密详情，加载阶段和详情阶段仍按统一三态策略启用 `FLAG_SECURE`。

### 普通相册与路径相册

1. 打开“图集”：远端相册按 cursor 分页；追加 cursor 失效时从首页重建，不把 cursor 当页码。
2. 在图集设置中修改名称和“最新优先 / 最早优先”：PATCH 只包含名称与排序，成功后详情顺序、图集列表和首页常用图集均刷新；智能图集没有排序切换入口。
3. 从成员照片菜单设为封面：请求包含该成员 ID 与中心焦点；非成员 ID 由服务端拒绝，客户端不得从全库绕过成员约束。
4. 清除封面：请求体必须实际包含 `"coverAssetId":null` 与 `"coverFocalPoint":null`，不能发送空对象。
5. 创建普通相册：不会出现路径或扫描控件；从时间线选择资产后成员列表刷新。
6. 批量添加或移除返回 HTTP 200 且 `failed` 非空：页面显示部分失败与首批失败原因，不错误显示全部成功。
7. 创建路径相册并选择初始目录：创建成功后成员仍为空，页面明确提示必须手动扫描。
8. 增加、更新或移除路径：先显示影响预览；确认时请求体与预览完全一致并携带相同 generation。
9. 应用路径变更后：不会自动扫描；点击“开始扫描”才创建同步运行。
10. 同步进入 `PENDING/RUNNING`：按退避节奏更新；到达 `SUCCEEDED/PARTIAL/FAILED/CANCELLED` 后停止轮询并刷新成员。
11. 路径离线或同步部分失败：既有成员仍保留，逐路径错误可见。
12. 删除任一相册：确认框明确不会删除资产或 NAS 文件；删除后返回远端图集列表。
13. 扫描历史首屏请求 `GET /albums/{albumId}/syncs?limit=100`，按创建时间、ID 倒序；深页只原样发送服务端 cursor，最大加载量不超过 500。
14. 让历史追加 cursor 失效：当前历史 Paging generation 从第一页重建，不把 cursor 解析成时间或页码。
15. 点击任一历史记录：详情请求使用 `/albums/{albumId}/syncs/{syncRunId}`，展示不超过 100 条路径快照及发现、复用、新增、移除、跳过统计。
16. 当前扫描仍在运行时点击旧终态记录：旧详情可查看，当前运行继续轮询；两条请求互不取消或覆盖选择状态。
17. 在 `PENDING/RUNNING` 时重建 Activity 或重新进入图集：依据相册 `lastRunId/lastRunState` 恢复观察，不创建新的 POST 扫描。
18. 活动运行到终态：历史、成员、相册计数、图集列表和首页刷新；AI worker 关闭时流程仍完整可用。
19. 在图集 A 的详情、目录、路径预览或同步详情请求未完成时打开图集 B，再让 A 的请求晚到：B 的内容、错误、选择和加载态均不得被 A 覆盖。
20. 同一图集连续点击刷新并让旧详情晚于新详情返回：页面只保留最新 request generation 的响应；响应 `Album.id`、路径 `albumId` 或同步 `albumId/runId` 漂移时显示契约错误。
21. 在图集 A 提交成员、设置、封面、路径或删除后立即离页：服务端成功事实不被伪取消，重新收集时恰好交付一次根级失效；随后打开图集 B 时不得显示 A 的反馈或数据。
22. 图集写操作仍在等待时让并行路径读取失败：错误可以显示，但 `isBusy` 必须保持，直到原 mutation 真正完成，期间不能重复提交同图集写操作。

### 评分、归档、私密与回收站

1. 在资产查看器设置 1–5 星或清除评分：请求发送目标值；清除请求体必须实际包含 `"rating": null`。
2. 归档资产：详情关闭并刷新来源列表；默认时间线和摘要不再包含该资产，已归档页可见。
3. 从已归档页取消归档：资产退出归档页并重新出现在默认时间线；原文件和资产 state 不改变。
4. 未解锁时进入私密空间或设置私密：显示当前账号口令表单；错误口令显示 `INVALID_CREDENTIALS`，不触发根登录跳转。
5. 解锁成功：只读取服务端 session 的 `privateAccessUnlocked` 与截止时间，私密列表使用 `private=true` cursor 分页。
6. 服务端授权过期：下一次私密请求收到 `PRIVATE_ACCESS_REQUIRED` 后回到解锁门，不继续展示旧分页内容。
7. 私密列表及其查看器：系统截图和最近任务预览被 `FLAG_SECURE` 阻止；应用进入后台后立即锁定并清除三层媒体缓存。
8. 从普通相册、首页、归档、搜索或回收站打开服务端标记为私密的资产：加载阶段即保持安全窗口，详情返回后继续阻止截图；服务端明确返回公开资产时才解除保护。
9. 移入回收站：资产退出所有普通列表，原文件仍在 NAS；回收站按删除时间显示并计算剩余天数。
10. 恢复：请求只带 ID，客户端不指定恢复目标状态；恢复后刷新时间线、相册计数和回收站。
11. 彻底清理：二次确认必须写明“不删除 NAS 原文件，未来扫描可能重新发现”；HTTP 200 部分失败逐项提示。
12. 解锁私密空间后返回普通页面再重新进入：进入瞬间不得复用旧 `isUnlocked` 或旧 Paging，必须重新请求 `/auth/session`，只有最新服务端响应确认后才请求 `private=true`。
13. 第一次私密 session 检查未完成时离页并重新进入，再让第一次检查晚于第二次返回：旧成功不得打开私密列表，旧失败不得覆盖第二次状态。
14. 提交解锁后立刻离页或让授权过期：旧解锁成功响应不能恢复本地授权；授权过期还应提交共享锁定并清除私密媒体缓存。
15. 点击锁定后让服务端 DELETE 失败：私密 Paging 必须从点击时立即关闭，错误可重试，但页面不得为了显示失败而恢复缩略图。
16. 并发执行解锁与后台锁定：活动解锁结束后必须再执行锁定；锁定提交前已经排队但尚未执行的旧解锁应被拒绝，服务端最终操作不能是旧解锁。
17. 提交恢复后立即离开回收站，再让请求成功：时间线、首页、图集计数、归档/私密、回收站、重复项、搜索和标签计数都必须收到根级换代；事件不得等到重新进入回收站才交付。
18. 提交彻底清除后立即离开回收站，再让请求成功：同样按 `PURGED` 换代全部资产消费者；重新进入回收站时目标资产不得复现，且不能因页面局部与根级 revision 各刷新一次。
19. 恢复或清除请求失败：忙碌状态清除并显示结构化错误，不发送 `RESTORED/PURGED`；首个请求未完成时点击另一条操作，不得产生第二个网络 mutation。

### Motion Photo 与任务中心

1. 打开带 `OPPO_MOTION_PHOTO_V2` 摘要的照片：默认显示静态原图，并出现“播放动态照片”。
2. 切换动态照片：Media3 请求 `/assets/{id}/motion-video`，服务端可观察到单段 Range；切回静态时播放器释放。
3. 普通照片、普通视频或 `motionPhoto=null`：不显示动态照片按钮，也不请求 `/motion-video`。
4. 打开任务中心：摘要与任务列表分别请求，任务列表使用不透明 cursor 且可按 state/kind 筛选。
5. 扫描摘要 `total=null`：只显示“已发现 N 个”，不显示百分比或假进度条。
6. 暂停队列：尚未领取和后续新任务进入 PAUSED，运行中任务继续完成；继续后 PAUSED 恢复 PENDING。
7. 取消活动任务：PENDING/PAUSED/RUNNING 可取消，终态任务没有取消入口。
8. `AI_INDEX` 与 `TAG_SCAN`：可以显示状态，但队列与任务都没有控制入口。
9. 摘要请求 A 挂起时手动刷新产生请求 B：A 的成功或失败晚到不得覆盖 B 的摘要、加载态或错误；离页后两者都不得写回旧页面。
10. 提交暂停、继续或取消后立即离开任务中心：服务端请求继续完成，离页不显示伪失败；请求未完成时重返页面仍显示对应忙碌态并拒绝重复提交，完成后当前页面刷新摘要和任务 Paging。

### 完全重复项

1. 从照片页右侧菜单打开“完全重复项”：列表仅显示 SHA-256 完全相同的在线副本组。
2. 滚动组列表和成员列表：两者 cursor 独立且原样回传；追加 cursor 失效时重建当前 Paging generation。
3. 打开重复组：显示各副本文件名、相对路径和大小；成员少于两个时显示返回刷新提示。
4. 点击“保留全部副本”：该组从默认列表消失；开启“包含已处理”后可见并能“恢复提醒”。
5. 上述操作前后核对 NAS：不得删除、移动或改写任何原文件。
6. 切换私密范围：未解锁时显示口令门，解锁后请求必须携带 `private=true`，且不混入普通重复组。
7. 私密重复列表、组详情及从其打开的资产查看器：截图和最近任务预览被 `FLAG_SECURE` 阻止，退到后台后立即锁定并退回照片页。
8. 私密 session 检查未返回时切回“普通”：旧成功响应不得把普通列表标成已解锁或开始收集 `private=true` Pager；旧失败也不得覆盖普通列表错误区。
9. 提交口令解锁后离开重复项页面，或执行“私密 → 普通 → 私密”：旧解锁结果不得直接恢复新页面授权；当前私密范围只能由新 `/auth/session` 检查确认。
10. 对 A 组执行“保留全部副本”后立即打开 B 组并让 A 的响应晚到：列表可刷新，但 B 详情必须继续保持；切换普通/私密范围后 A 的成功或失败均不得写入新范围。
11. 服务端返回 `PRIVATE_ACCESS_REQUIRED` 后立即重新输入口令：客户端只清本地私密 Pager，不额外补发延迟锁定请求，新解锁不得被旧清理动作撤销。

### XMP 照片信息备份

1. 服务端 `health.xmpExport.available=false`：页面显示未配置提示，不请求预估、创建或历史；时间线等其它功能继续可用。
2. 默认点击“检查可备份内容”：请求体包含 `includePrivate=false` 且不发送 `libraryIds`，只显示估算，不创建任务或写文件。
3. 预估成功后创建：请求必须携带预估返回的精确 `resolvedLibraryIds`；预估为空时按钮禁用，不能用缺席字段误导为全库。
4. 开启“包含私密照片”：要求当前账号口令，成功后页面启用 `FLAG_SECURE`；错误口令不触发根登录跳转。
5. 私密授权在预估后、创建前过期：收到 `PRIVATE_ACCESS_REQUIRED` 后丢弃旧预估，重新解锁后仍须再次估算。
6. 新任务返回 202：接受新建或命中同范围未完成 run，历史刷新；页面关闭后任务继续由服务端运行。
7. 历史按不透明 cursor 分页；追加 cursor 失效时从第一页重建，不能把少于 limit 误判为到底。
8. 列表或详情存在 `PENDING/RUNNING`：每 5 秒刷新；进入任一终态后停止轮询。
9. 详情只显示脱敏摘要和 `xmp/<snapshotId>` 逻辑目录，不显示宿主机绝对路径、逐项资产、源路径或错误正文。
10. XMP 快照前后核对 NAS：原照片字节不变，原文件旁没有 sidecar；相册关系和编辑配方仍只依赖数据库备份。
11. 历史刷新或活动详情返回 `RATE_LIMITED`、离线或其它错误：自动轮询立即停止，等待超过两个轮询周期也不得产生新请求；错误保留 `logId`，只有用户点击手动重试后才允许恢复轮询。
12. 延迟能力检查、预估或创建响应后离开 XMP 页面：旧响应不得恢复私密范围、预估卡、任务详情、忙碌态或错误；重新进入重新执行能力检查并从历史读取服务端任务。
13. 预估请求未返回时执行取消：旧 preview 成功或失败均不得重新出现确认卡；随后新预估可以正常显示。
14. 打开运行详情后立即关闭，并让详情响应晚到：面板不得重新打开；打开另一个运行后旧响应不得覆盖新运行。
15. 提交私密解锁后关闭口令框或离开路由：旧解锁响应不得恢复 `privateUnlocked/includePrivate`，也不得自动续接先前待执行的预估。

### 系统状态与本机缓存

1. 从照片库菜单进入系统状态：请求一次认证后的 `GET /system/status`；退出后重新进入再次请求，不复用上次求值冒充实时状态。
2. `alerts=[]`：显示“当前没有运维告警”和服务端 `generatedAt`，不出现已读、历史或推送开关。
3. 分别返回四种告警：标题、对象、当前值、阈值及 `BYTES/COUNT` 单位正确；未知机器码应作为契约错误暴露，不能静默错配建议。
4. 派生目录或媒体库空间不足：只提示在服务端/NAS 处理；不得提供会误导成远端释放空间的本地清理按钮。
5. 派生缓存过高或任务连续失败：可进入任务中心查看；从任务中心返回时回到系统页，不能丢失上下文。
6. 读取本机缓存：分别显示 Coil 内存、Coil 磁盘和 OkHttp 认证缓存，磁盘合计不包含 APK、偏好设置或服务端存储。
7. 确认清除本机媒体缓存：三层缓存归零或下降，当前 Cookie 会话与服务器地址仍有效，重新打开照片会重新下载。
8. 清除前后核对服务端与 NAS：`DERIVATIVE_CACHE_HIGH` 数值、服务端派生文件、数据库记录和 NAS 原文件均不因本地操作改变。
9. 系统页不请求 `/system/ai-settings`，也不显示 AI 地址、模型、密钥或配置入口。
10. 连续刷新两次服务端状态：第一次成功或失败即使忽略取消并最后返回，也不得覆盖第二次状态、错误或加载态。
11. 缓存读取挂起时开始清理：清理必须立即失效旧读取；清理完成显示新快照和成功反馈后，旧快照晚到不得恢复清理前字节数。清理期间再次刷新只更新服务端状态，不启动并行缓存读取。

### 回忆日期屏蔽

1. 从照片库菜单进入回忆屏蔽：首屏请求 `GET /memory-exclusions?limit=100`，追加 cursor 原样回传；游标失效后从首页重建列表。
2. 未选全日期或开始日晚于结束日：显示本地错误，不发送创建请求。
3. 选择合法范围并提交：请求体精确包含 `kind=DATE_RANGE`、`dateFrom` 和 `dateTo`；服务端重复范围返回既有规则的 `201` 时只显示成功。
4. 服务端返回既有 `PERSON` 规则：页面可显示并删除，但没有新增人物规则入口；任何页面都不出现地点屏蔽。
5. 删除规则：发送无 body 的 `DELETE /memory-exclusions/{uuid}`；成功后规则列表和 `/home` 都刷新。
6. 新增或删除前后核对普通时间线、搜索、图集和 NAS：资产可见性、状态及原文件均不变化，只有首页“往年今日”结果变化。
7. 用拍摄 offset 与设备时区跨日的资产验证：回忆归属以服务端保存的资产本地月日为准，Android 不二次改日。
8. 创建日期范围请求挂起时继续选择下一组日期：旧请求成功后保留新草稿，只结束旧忙碌态并刷新规则；忙碌期间再次点击创建或删除不得产生第二个 mutation。
9. 提交新增或删除后立即离开页面，并让服务端成功响应在无订阅期间返回：重新进入时仍刷新规则 Paging 和首页一次；同一事件消费后再次进入不得重复刷新。

### 自动化契约覆盖

- 服务地址规范化、非法路径与 `/api/v1` 去重。
- 登录响应 Cookie 自动进入后续会话探测。
- 401 在根收集器建立前仍可锁存、并发突发只清理一次、失效前旧 bootstrap 响应晚到不覆盖登录页。
- Cookie 持久账本的 JSON 往返、后写覆盖、删除、精确到期、重复恢复，以及 host/path/secure 匹配隔离。
- Android Keystore 仪器测试覆盖密文落盘不泄漏明文、CookieJar 重建恢复、请求域约束、显式清理及损坏密文启动自愈。
- 直接连接不同服务器时，旧 Cookie 与缓存清理发生在新地址 health/session 探测之前。
- 列表与摘要共用的筛选映射、标签稳定排序和参数边界。
- 高级筛选整日日期边界、逆序范围拒绝、标签三态与激活维度计数。
- 创作入口固定照片/普通/未归档筛选、收藏目标状态，以及 2/3 列网格密度的有限状态切换。
- `/folders` 虚拟根、媒体库/目录模型、相对路径安全和不透明 cursor 原样传递。
- Paging 首屏、追加页、不透明 cursor 与 `INVALID_CURSOR` 失效行为。
- 缩略图尺寸和 `contentHash` 缓存版本参数。
- 64 位小写 SHA-256 的长度、字符集和大小写边界；时间线、相册封面、重复项及编辑渲染对畸形版本键的一致拒绝与原图回退。
- 重复项 route/scope/check/auth/review/selection token 的精确匹配；分域切换、新授权操作和组选中变化会独立使旧请求失效。
- 详情扩展字段、收藏目标状态与 HTTP 200 部分失败。
- 批量结果允许合法部分成功，同时拒绝成功/失败重复、同一目标重叠、请求目标漏报和未请求目标夹带。
- `FLAG_SECURE` 状态矩阵覆盖私密列表、私密重复项、XMP 私密范围、任意来源私密资产，以及查看器加载中未知状态的保守保护。
- 六种资产状态的原图读取白名单、非可浏览状态 URL 构造拒绝、Motion Photo 状态隔离，以及处理中资产仍可使用版本化缩略图。
- 照片信息的原时区格式化、异常时间安全回显、二进制文件大小、媒体时长以及资产状态/时间来源中文映射。
- 派生图片路径识别、`503 + Retry-After` 秒数/HTTP 日期解析、5 秒封顶、两次上限、零秒去重及非派生请求隔离。
- 结构化 API 错误的消息、`logId`、可重试事实保留；空 ID 和本地网络异常不生成伪诊断编号。
- 资产变更到消费者集合的精确矩阵、空集合、多个变更并集去重，以及回收站三类操作的全消费者换代。
- 标签 Long ID、Unicode 名称、游标列表、创建、重命名、删除影响数、单图添加和移除端点。
- 标签库 500 条上限、`INVALID_CURSOR` generation 失效和已删除 ID 从 AND/OR/NOT 三组筛选条件精确移除。
- 标签库相同关键词重复提交的 Paging 重建、无订阅窗口内成功事件的 Channel 保留、mutation 串行拒绝，以及重命名响应 ID 漂移时不伪造成功或错误失效。
- 相册和成员游标分页、`INVALID_CURSOR`、普通相册成员 DELETE 请求体。
- 路径相册创建不扫描、预览/应用请求体一致、相对目录浏览和显式扫描端点隔离。
- 路径同步历史 cursor、500 条上限、`INVALID_CURSOR` 换代、trigger/状态/计数模型与详情 GET 路径。
- 图集设置 PATCH 的名称/排序字段、成员封面中心焦点和清除封面的两个显式 null。
- 图集详情同对象重复刷新、跨对象详情/路径晚到拒绝、离页 mutation 成功事件保留、响应图集 ID 漂移，以及辅助读取错误不释放 mutation 锁。
- 评分 null 显式序列化、归档/私密目标状态、私密解锁/锁定端点。
- 私密路由重返复核、旧 route session/解锁响应拒绝、授权过期失效、锁定失败 fail-closed，以及解锁/锁定协调器的最终锁定顺序和排队旧解锁淘汰。
- 回收站独立 cursor、`INVALID_CURSOR`、恢复与 purge 请求路径。
- 回收站恢复/清除的类型化 Channel 事件包含原资产 ID；未收集期间成功仍可单次交付，失败无事件，忙碌期拒绝第二个 mutation，并由现有失效矩阵验证两类事件换代全部消费者。
- Motion Photo 专用组件 URL、任务 cursor/筛选、摘要未知总数与三类控制端点。
- Media3 播放错误对 `401/403/404/416/503`、网络异常和未知 HTTP 状态的确定性文案，以及仅 416 重置到位置 0 的恢复策略。
- AI 任务类型只读控制边界。
- 重复组 SHA-256 模型校验、缩略图内容版本参数与响应解析。
- 重复组与成员的独立 cursor、`includeReviewed`/`private` 精确参数和 `INVALID_CURSOR` 失效行为。
- review/reopen 的 PUT/DELETE 方法、路径、私密查询参数与空请求体。
- 文件名搜索 trim 后的关键词、字面通配字符、组合筛选以及列表/摘要参数一致性。
- 搜索 3～255 Unicode code point 边界、代理对安全截断、同筛选重复提交的 Paging generation 与旧摘要拒绝写回。
- 年/月/日分组标题、今天/昨天标识、`takenAt` offset 边界与 `2 + 3 + 2` 编辑式行节奏。
- 时间线摘要 generation、完整筛选与粒度三重身份；同条件重复刷新时旧成功/失败拒绝写回。
- `/home` 五区块解析、无 query 聚合路径、总空态和资产/图集固定上限。
- 首页刷新期间再次失效会建立新 generation；不响应取消的旧成功或失败回调不能覆盖最新聚合。
- 编辑配方范围校验、旋转/镜像裁剪坐标、编辑历史 cursor 与精确 POST/PATCH 请求体。
- 预期/目标版本的 JSON `null` 显式序列化、`activeEdit` 解析和 CURRENT/STALE 媒体 URL 分流。
- XMP 能力开关、默认/精确范围请求体、预估与运行摘要解析、逻辑路径及 SHA-256 约束。
- XMP 历史 cursor、`INVALID_CURSOR`、运行终态判断和空预估范围保护。
- XMP 轮询策略覆盖活动且无错误、活动但失败、没有活动任务三种状态；结构化错误保留机器码，失败后不自动循环。
- 手写游标分页覆盖非首页 `INVALID_CURSOR` 判定、旧集合丢弃、一次重建上限与循环 cursor 拒绝。
- 协程失败边界验证 `CancellationException` 原样重抛、普通异常无副作用，并由根会话竞态测试继续覆盖旧 bootstrap 不得恢复内容。
- 资产 request token 覆盖同 ID/同 generation、不同 ID、旧 generation 与空当前资产；编辑完成事件显式验证所属 asset ID。
- XMP request token 覆盖 route 与 operation generation 同时匹配、关闭局部交互失效和离开路由失效；轮询策略测试继续验证失败熔断。
- 系统状态只读 GET、四种告警与 `BYTES/COUNT` 解析、RFC 3339 时间和非负数值边界。
- 本地缓存三项模型合计、字节/次数格式和不触碰会话/NAS 的代码路径。
- 服务端状态 generation 与缓存读/清共享 generation 的竞态覆盖；清理前旧快照不能覆盖清理结果。
- 回忆规则 DATE_RANGE/PERSON 响应形状、逆序日期拒绝、仅日期创建和无 body 删除契约。
- 回忆规则不透明 cursor、500 条客户端上限与 `INVALID_CURSOR` generation 失效。
- 回忆创建草稿 revision、忙碌期串行提交和无订阅窗口的 Channel 失效事件保留。

## 视觉验收矩阵

| 设备类型 | 建议视口 | 重点验收内容 |
|---|---|---|
| 紧凑型手机 | 360 × 800dp | 选择器不与标题冲突，三列图片仍可辨识 |
| 参考尺寸手机 | 393 × 852dp | 整体留白和设计稿比例 |
| Android 高屏 | 412 × 915dp | 底栏安全区与第二日期组可见性 |

每个视口都必须检查：

- 页面内容没有绘制到状态栏图标下方。
- 主内容左右边缘统一对齐在 `24dp` 基线。
- 图片间隙保持 `4dp`，没有宽度不一致的背景漏缝。
- 阴影柔和，不出现灰色矩形边界。
- 图片圆角处不暴露源图片直角。
- 合集元信息保持居中，成员标识不换行。
- 手势导航和三键导航都不会与悬浮底栏重叠。
- 所有浅色悬浮控件都有连续高光边缘，不出现黑块、透明穿孔、捕获坐标错位或 RenderEffect 失败。
- 毛玻璃只处理背景合成，图标和文字本身不得被模糊。

## 像素对比方法

叠图前应把设计稿和模拟器截图归一到相同的内容宽度。排除灵动岛、iOS 状态栏和 Home Indicator 等平台专属区域。

差异修正优先级：

1. 页面主边距。
2. 顶部栏和标题基线。
3. 拼贴图片几何结构。
4. 悬浮按钮和底栏。
5. 字体层级。
6. 阴影柔和度。

Android 系统字体造成的轻微字形差异可以接受；影响整行基线或布局尺寸的偏移不可接受。
