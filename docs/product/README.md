# 产品范围与功能接入状态

## 目标

交付 Android 16 原生 PhotoTube 客户端。现有高保真相册界面继续作为视觉基线，功能按照服务端稳定契约分阶段接入。

当前功能阶段已完成服务器配置、会话认证、认证后账号与管理、回忆日期屏蔽、远端时间线、高级筛选、基础文件名搜索、媒体查看、非破坏性图片编辑、XMP 信息快照导出、系统状态与本机缓存管理、OPPO Motion Photo、收藏、评分、归档、私密空间、回收站、人工标签库与单图标签管理、普通相册、路径相册、任务中心与完全重复项核对。

## 当前真实功能

- 首次启动输入 PhotoTube 服务根地址。
- 自动补全 `http://`，并确保 `/api/v1` 只追加一次。
- 保存地址前请求 `/health`，数据库不可达或迁移 dirty 时拒绝进入。
- 冷启动请求 `/auth/session`，区分已登录、需要登录和服务端口令未初始化。
- 登录使用 Cookie 会话；Cookie 由 Android Keystore AES-GCM 加密后持久化，重启恢复仍严格遵守 host、path、secure 与到期边界。
- Retrofit、Coil 与 Media3 共用同一个 OkHttpClient、CookieJar 和 HTTP 缓存。
- 全局 `401 UNAUTHORIZED` 会锁存并返回登录页；并发媒体/API 失效只清理一次，旧连接或会话响应不能在随后重新恢复内容页。`INVALID_CREDENTIALS` 只显示在登录表单。
- 点击头像进入“账号与管理”，可查看当前用户和服务器地址、进入后台与照片库管理，并经二次确认退出登录或切换服务器。
- 退出只有在服务端确认删除会话后才回登录页；失败时保留当前会话供重试，不把本地 Cookie 清理冒充服务端登出。
- 切换或直接连接另一服务器不会被旧服务器离线阻断；新地址探测前，本机旧 Cookie、服务地址和三层认证媒体缓存边界已清除，旧服务端未确认登出时给出明确警告。
- 照片页通过 `GET /assets` 使用 Paging 3 游标分页，不解析或自行生成服务端 cursor。
- 同一份筛选对象同时驱动资产列表与 `GET /assets/timeline-summary`。
- 缩略图通过 Coil 和共享认证客户端加载，URL 固定包含尺寸与 `contentHash` 版本参数。
- 只有规范的 64 位小写 SHA-256 能作为媒体版本参数；异常值显示占位或回退原图，不会造成缩略图、封面与编辑渲染缓存串用。
- 刷新、追加、空结果、处理中、网络错误和可重试服务端错误都有明确界面状态。
- 点击资产可进入详情；照片由 MD 占位过渡到 `/original`，支持 1–3 倍手势缩放。
- 视频通过 Media3 播放 `/original`，Range 请求沿用同一认证客户端；HTTP 416 可由用户从头重试，其它媒体错误显示对应原因而不自动循环请求。
- 收藏使用幂等目标状态；HTTP 200 中的逐项失败仍显示为失败。
- 所有资产批量写入会核对成功与失败集合是否精确覆盖请求；合法部分成功显示成功数和失败原因，矛盾、重复或漏报响应不会被当成完成。
- 单图标签支持搜索已有标签、创建并添加、移除以及标签游标续页，ID 全程使用 `Long`。
- “账号与管理”可进入人工标签库：按使用资产数分页搜索、新建、重命名或删除标签；删除结果显示实际受影响资产数。
- 删除标签会清理当前高级筛选中的对应 ID，并刷新资产详情、全部资产列表、智能图集与首页；照片和 NAS 原文件不受影响。
- 图集页通过 `GET /albums` 使用 Paging 3 游标分页，支持创建普通相册和路径相册。
- 图集详情支持重命名、拍摄时间升降序、从成员照片设置封面和显式清除封面；更新后图集列表与首页同步失效。
- 普通相册详情支持从远端时间线批量添加资产、逐项移除，并显示 HTTP 200 中的部分失败信息。
- 路径相册支持浏览来源目录、读取已配置路径、预览路径影响、携带同一请求与 generation 应用变更。
- 保存路径只更新配置，不会暗中扫描；扫描只能由用户明确点击后通过 `POST /albums/{id}/syncs` 触发。
- 路径同步详情按 `1/2/3/5` 秒退避轮询，并展示终态和逐路径错误；离线路径不会清空既有成员。
- 路径相册展示完整扫描历史并按游标增量加载；重新进入页面会自动恢复观察仍在等待或运行的扫描。
- 点击历史可查看逐路径发现、复用、新增、移除、跳过与脱敏错误，删除过的路径仍使用运行时快照保持可解释性。
- 删除相册只删除相册配置与关系，不删除资产记录或 NAS 原文件，确认框明确说明这一边界。
- 资产查看器支持 1–5 星评分与清除评分、归档/取消归档、设为/移出私密空间以及移入回收站。
- 归档页与私密页复用资产游标分页；归档资产退出默认时间线，私密资产只在服务端会话短时解锁后可见。
- 私密空间使用当前账号口令解锁，最长 15 分钟；服务端授权过期会回到解锁页，不把客户端倒计时当授权事实。
- 私密页面及任意入口打开的私密资产查看器都启用 `FLAG_SECURE`；查看器加载中先保护，确认公开后才解除。应用进入后台时立即锁定私密访问并清空 Coil 内存/磁盘缓存和 OkHttp 缓存。
- 回收站使用独立 `GET /trash` 游标，按删除时间排序，显示剩余保留期并支持恢复。
- 彻底清理只删除 PhotoTube 数据库记录和派生缓存，不删除 NAS 原文件；确认框说明未来扫描可能重新发现。
- 查看器识别 `OPPO_MOTION_PHOTO_V2` 后提供静态原图与动态短视频切换；短视频通过共享认证 Media3 DataSource 读取 `/motion-video` Range。
- “账号与管理”页可进入任务中心；任务按状态和类型筛选并通过不透明 cursor 分页。
- 任务摘要在总数未知时显示“已发现 N 个”，只在 `total` 明确时展示进度条。
- 非 AI 队列支持暂停/继续，活动任务支持协作取消；AI 索引和 AI 标签扫描只读展示，不暴露控制入口。
- 完全重复项仅按 SHA-256 展示字节级相同的在线文件，按不透明 cursor 分页并显示理论可释放空间。
- 普通和私密重复组严格分开；私密范围需要服务端短时解锁，列表、组详情与资产查看器全程启用 `FLAG_SECURE`。
- “保留全部副本”只写入可逆的已处理事实，可恢复提醒；客户端不自动删除、移动或改写 NAS 文件。
- 照片页顶部搜索已接入文件名大小写不敏感字面子串查询，关键词去空后限制为 3～255 个 Unicode 字符，emoji 不会按两个 UTF-16 单元误计或被截断。
- 搜索可组合照片/视频、仅收藏和精确星级；列表与日粒度摘要复用同一 `AssetFilter`，不会出现计数与内容漂移。
- 照片页顶部筛选可组合照片/视频、已收藏/未收藏、精确星级、拍摄日期、媒体库相对目录和三组标签条件。
- 目录通过虚拟根逐层展开，只保存媒体库 ID 与相对路径；不读取或展示服务端宿主机绝对路径，离线媒体库不能被选中。
- 标签支持“全部包含 / 任一包含 / 排除”三种互斥语义；应用筛选会同时重建时间线分页和当前粒度摘要，清除后恢复默认普通时间线。
- 远端时间线支持年/月/日三种分组粒度，切换时请求对应摘要并取消旧请求，不让过时响应覆盖当前选择。
- 已加载资产按 `takenAt` 自带 offset 分组，不套用手机当前时区改写归属；日视图使用参考稿的 2+3+2 编辑式拼贴节奏。
- 底部导航只保留“所有照片 / 相册”两个稳定一级入口；首页摘要与后台任务不占用底部位置。
- 首页一次载入往年今日、最近拍摄、最近入库、常用图集和任务摘要；往年今日为空时隐藏整个区块。
- 首页资产、图集和任务卡片分别打开真实查看器、图集详情和任务中心；它是固定上限的摘要，不代替完整分页接口。
- JPEG/PNG 照片可从查看器进入非破坏性编辑器，调整裁剪、90°旋转与水平/垂直镜像；保存只创建不可变配方版本，不修改 NAS 原文件。
- 非破坏性编辑从照片查看器进入，不再为“创作”设置一级底部入口。
- 编辑历史可分页读取并切回任一仍基于当前原图的版本，也可切回原图且保留全部历史；原图内容变化后的 `STALE` 版本只展示不激活。
- 保存与版本切换均携带当前激活版本作为并发基线，`409` 时重新读取服务端状态，不用最后写赢覆盖其它客户端修改。
- 时间线、相册、首页和查看器在 `activeEdit.sourceState=CURRENT` 时统一读取内容寻址的编辑渲染；`STALE` 时回退原图。
- “账号与管理”可进入“照片信息备份”：先读取 `health.xmpExport.available`，未配置独立 export volume 时只禁用该能力，不影响浏览。
- XMP 导出先显式预估，再以预估返回的精确媒体库 ID 创建后台快照；历史和详情只显示脱敏计数、状态、逻辑目录与摘要哈希。
- 运行中的 XMP 快照每 5 秒刷新；终态或刷新失败时立即停止自动轮询，限流不会产生后台请求循环，用户可稍后手动恢复；相同范围已有未完成任务时接受服务端返回的同一运行。
- 包含私密照片的预估和创建必须使用服务端短时授权，页面进入私密范围后启用 `FLAG_SECURE`；后台锁定后重新进入会重新探测 session。
- “账号与管理”可进入系统状态页，每次进入读取四类服务端即时告警；没有告警时显示本次求值时间，不建立虚假历史或已读状态。
- 服务端派生缓存告警只提供说明和任务中心入口；Android 不伪造服务端清理按钮，也不会把本机缓存清理说成服务端治理。
- 本机缓存页分别显示图片内存、图片磁盘和认证 HTTP 磁盘占用；确认清除后保留登录、服务器地址、相册、业务数据和 NAS 原文件。
- “账号与管理”可管理回忆日期范围屏蔽；新增或删除后刷新规则列表与首页“往年今日”，普通时间线、搜索、图集和 NAS 文件不受影响。
- 既有人物回忆规则可以显示和删除，但当前 Android 不允许新增；地点屏蔽已取消，不提供伪入口。

## 仅保留的视觉基线

- 静态 `PhotoTimelineScreen`、`CollectionsScreen` 和 `MockAlbumRepository` 仅保留为视觉回归基线，认证后的根导航不再使用它们。

## 已实现状态

- 所有已接入页面的服务端错误正文均可长按选择；响应包含 `logId` 时显示“复制日志 ID”，便于提交给管理员排查。应用不会把日志 ID 自动写入系统日志或埋点。
- 在资产查看器连续完成多个操作后，退出时会按操作语义同时刷新时间线与首页、搜索、相册、归档/私密、回收站等相关页面，不再只刷新打开查看器的来源页。

### 远端照片时间线——默认启动页面

- 白色与浅灰组合的沉浸式画布。
- 顶部包含头像、搜索操作和筛选操作。
- 中文大标题 `照片`；首个远端资产决定月份上下文，摘要提供总数。
- 资产按当前年/月/日粒度分组，组内使用主图双列、三等分和双等分循环的编辑式拼贴，仍由 Paging 增量加载。
- `PROCESSING` 资产显示处理中占位；视频资产显示类型标识。
- 顶部筛选使用草稿式底部面板，只有“应用”才改变查询；激活时顶部红点和条件摘要持续可见。
- 日期范围含首尾两天；目录包含全部后代；标签支持 AND/OR/NOT，列表和摘要不会使用不同条件。
- 底部悬浮双项滑块导航，仅显示“所有照片 / 相册”，并避让系统导航栏。

### 资产查看器

- `BROWSABLE` 照片加载原图；`PROCESSING` 只尝试版本化缩略图并显示处理中，`DISCOVERED`、`FAILED`、`OFFLINE` 和 `TRASHED` 只显示诚实状态，不把详情 200 误判成原媒体可读。
- 原图按当前显示约束下采样，避免整张高分辨率位图无条件常驻内存。
- 普通视频交给 Media3/ExoPlayer，底层 `OkHttpDataSource` 保留 Range、Content-Range 和 Content-Type 语义。
- 资产查看器采用浅色系统图库结构：顶部显示来源与拍摄时间，底部显示真实相邻照片胶片，以及分享、收藏、信息、编辑和删除五个高频动作；文件名、尺寸、路径、标签和管理能力按需进入照片信息或“更多”。
- 从全部照片打开时可点击胶片或左右滑切换当前已加载照片；上滑打开照片信息，单击切换沉浸态，双指保留 `1–3×` 缩放。连续浏览产生的资产变更会合并后再通知根导航。
- “照片信息”是无描边的只读底部面板，按内容、拍摄、文件和 PhotoTube 分组展示；路径、哈希、媒体库 ID 与资产 ID 可长按选择。
- 拍摄时间保留响应携带的原始 UTC 偏移，不转换成手机时区；状态覆盖发现中、可浏览、处理中、失败、离线与回收站。
- 标题、描述仅在服务端已有值时只读显示；GPS、标题、描述和拍摄时间均没有编辑入口。
- 缩略图或当前编辑渲染暂未生成时，客户端遵守服务端 `Retry-After` 做有界等待；不会无限刷新，也不会把相同行为套到原图、视频或业务写请求。
- 会话过期、退出或切换服务器时立即清内存媒体缓存，并清除 Coil 磁盘缓存与 OkHttp HTTP 缓存。

### 非破坏性图片编辑

- 入口只对 `BROWSABLE` 的 JPEG/JPG/PNG 照片开放，并要求存在 64 位小写十六进制 `contentHash`。
- 裁剪使用百万分之一整数保存，最小边长为 `10,000 PPM`；旋转只允许 `0/90/180/270`。
- 编辑器从原图计算预览，保存时发送完整配方、原图哈希与预期当前版本，成功后立即切换到新版本。
- 草稿退出或带草稿切换历史前必须确认；历史版本不会被客户端删除或改写。
- 当前原图哈希变化后，旧版本标为 `STALE` 并禁止重新激活，查看器回退 `/original`。

### XMP 照片信息备份

- XMP 是用户显式创建的不可变迁移快照，不是日常编辑旁路，也不是数据库完整备份。
- 预估只计算当前时点数量，不创建任务、不冻结资产集合、不写文件；确认开始时服务端才重新验证范围并固化一致快照。
- 客户端不能输入宿主机路径，输出只进入部署时配置的独立 export volume；界面只展示 `xmp/<snapshotId>` 逻辑目录。
- 导出保存标签、评分、拍摄时间和位置等标准字段；相册关系、收藏、私密状态、编辑配方和审计仍依赖数据库备份。
- 历史固定按 `(createdAt DESC, id DESC)` 不透明 cursor 分页；`INVALID_CURSOR` 会重建 Paging generation。
- 运行状态包含 `PENDING/RUNNING/SUCCEEDED/PARTIAL/FAILED/CANCELLED`，详情不提供逐项资产、源路径或错误正文。

### 系统状态与本机缓存

- 系统状态只读取认证后的 `/system/status`，展示派生目录/媒体库磁盘空间、派生缓存高水位和连续任务失败告警。
- 告警文案明确区分服务端/NAS 与 Android 本机；磁盘容量必须在部署端处理，任务类告警可打开任务中心继续核对。
- 本机缓存统计覆盖 Coil 内存、Coil 图片磁盘和 OkHttp 认证 HTTP 磁盘，不把 APK、用户设置或服务端存储混入数字。
- 清除需要二次确认，只让已缓存照片下次重新下载；不会退出登录、删除服务端派生文件或修改 NAS 原文件。
- AI 设置仍冻结，系统状态页没有 AI 地址、模型、密钥或控制入口。

### 回忆屏蔽

- 规则列表按服务端时间与 ID 游标分页，不根据当前屏幕内容自行推导规则。
- 新建只接受含首尾两天的日期范围；重复范围由服务端幂等返回既有规则，不在客户端制造重复成功状态。
- 删除规则只恢复其参与首页“往年今日”的资格，不恢复或修改其它资产状态。
- 规则是数据库用户事实，需要跟随服务端备份；Android 只保留页面瞬时草稿。

### 合集概览

- 与照片时间线共用顶部和底部操作区，数据来自远端相册游标接口。
- 相册卡片显示封面、名称、类型、成员数量与更新时间。
- 支持加载、空状态、失败重试和追加页失败状态。
- 点击卡片进入对应相册详情；创建入口支持普通相册和路径相册。

### 普通相册与路径相册

- 两类可排序图集支持“最新优先 / 最早优先”，智能图集保持服务端规则定义的固定顺序。
- 任一成员照片都能通过照片菜单设为封面；默认使用中心焦点。清除封面后回到服务端默认封面策略。
- 图集名称、排序、封面、成员或路径结果变化后，详情、图集列表和首页常用图集使用同一失效链路，不保留第二份本地真相。
- 普通相册可以从远端资产列表中选择最多 `500` 个资产添加，也可逐项移除。
- 批量接口的 `failed` 不会被 HTTP 200 掩盖，页面会列出首批失败原因。
- 路径相册创建时可选择初始来源目录，但创建完成后仍须用户明确点击“开始扫描”。
- 路径增加、更新和移除必须先预览影响，再以同一个请求体和 `expectedGeneration` 应用。
- 同步运行状态区分 `PENDING`、`RUNNING`、`SUCCEEDED`、`PARTIAL`、`FAILED` 与 `CANCELLED`。
- 扫描历史固定按创建时间与 ID 倒序分页，区分初始、手动与媒体库联动三种来源；查看旧记录不会停止当前运行。
- 应用重建或重新进入详情时，若相册摘要指向非终态运行，客户端会恢复有界退避轮询；完成后刷新成员、历史、图集列表与首页。
- 删除两类相册都不会删除资产或 NAS 文件。

### 人工标签库

- 标签列表固定按使用资产数倒序、ID 升序分页；搜索词最长 120 个 Unicode 字符，不能用当前页重新排序冒充服务端全局结果。
- 新建只创建数据库标签；重命名保留标签 ID 和全部资产关系，已有筛选仍继续引用同一标签。
- 删除会在服务端事务内移除全部资产关系和派生 ID，界面二次确认并展示实际影响数；它不是删除照片，也不会写 NAS。
- AI worker 缺席不影响人工标签管理。页面没有 AI 扫描、AI 设置或规则扫描的旁路入口。

### 账号与服务器

- 账号页使用服务端会话返回的显示名与用户名，不展示 token，也不在 Android 维护独立用户资料。
- 退出登录调用需认证的 `POST /auth/logout`。成功后保留服务器地址，方便重新登录；失败时留在账号页并显示服务端错误或网络错误。
- 切换服务器会先尝试注销旧服务端会话，再清除本机 Cookie、Coil 内存、Coil 磁盘、认证 HTTP 缓存和已保存地址，随后进入服务器配置页。
- 旧服务器不可达时仍允许切换，但配置页会说明旧服务端会话未获确认，避免给出虚假的安全保证。
- 两个动作都不删除照片、相册、PhotoTube 数据、服务端派生文件或 NAS 原文件。

## 真实导航流程

```text
应用启动
└── 远端照片时间线
    ├── 点击资产 → 资产查看器
    │   ├── 收藏 / 标签 → 原地更新详情
    │   ├── 非破坏性编辑 → 裁剪 / 旋转 / 镜像 → 保存新版本 / 切换历史 / 回原图
    │   └── 返回 → 刷新远端照片时间线
    ├── 顶部搜索 → 文件名查询 / 类型 / 收藏 / 星级 → 搜索结果 → 资产查看器
    ├── 顶部筛选 → 类型 / 收藏 / 星级 / 日期 / 目录 / 标签三态 → 应用 / 清除 → 时间线换代
    ├── 底部“相册” → 远端相册列表
    │   ├── 新建普通图集 → 图集详情 → 添加/移除照片
    │   └── 新建或打开路径图集 → 路径预览/应用 → 显式扫描 → 活动状态 / 历史 / 逐路径详情
    ├── 点击头像 → 账号与管理
    │   ├── 任务中心 → 扫描 / 导入 / 后台处理进度与队列控制
    │   ├── 系统状态与缓存 → 即时告警 / 本机媒体缓存
    │   ├── 已归档 / 私密空间 / 回收站 / 完全重复项
    │   ├── 私密空间 → 口令解锁 → 私密资产 → 后台或手动锁定
    │   ├── 回收站 → 恢复 / 彻底清理 PhotoTube 记录
    │   ├── 完全重复项 → 普通/私密分域 → 副本路径核对 → 保留全部/恢复提醒
    │   ├── 照片信息备份 → 能力检查 → 范围预估 → 运行历史 / 脱敏详情
    │   ├── 回忆屏蔽 / 标签管理 → 新增 / 删除 / 统一刷新消费者
    │   ├── 退出登录 → 服务端删除会话 → 清本机认证缓存 → 登录页
    │   └── 切换服务器 → 尽力注销旧会话 → 清旧边界 → 服务器配置页
    └── 任意资产列表点击资产 → 资产查看器 → 状态操作后刷新来源列表
```

底部“所有照片 / 相册”、顶部高级筛选、文件名搜索以及账号与管理页中的全部入口均执行真实业务操作；底部不存在无业务含义的装饰按钮。
