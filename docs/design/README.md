# 视觉还原规范

## 设计稿解释原则

第一张设计稿定义照片时间线、留白、字体层级、编辑式拼贴和悬浮底栏。第二张设计稿定义合集的已填充状态和空状态。

应用运行在 Android 上，因此保留 Android 原生系统栏，不模拟 iPhone 灵动岛和 Home Indicator。像素对比时应排除这部分平台差异。

## 核心设计令牌

令牌定义位于 `app/src/main/java/com/yunai/phototube/ui/theme/DesignTokens.kt`。

| 令牌 | 数值 | 用途 |
|---|---:|---|
| Background | `#F8F9FB` | 页面画布和系统栏 |
| Surface | `#FFFFFF` | 悬浮控件表面 |
| Ink | `#17181A` | 主文字和图标 |
| Muted | `#85878D` | 时间、地点与辅助信息 |
| 页面水平边距 | `24dp` | 主内容对齐基线 |
| 图片间隙 | `4dp` | 拼贴图片之间的缝隙 |
| 图片圆角 | `12dp` | 时间线图片 |
| 顶部悬浮按钮 | `52dp` | 搜索和筛选触控区域 |
| 底部导航 | `224 × 52dp` | “所有照片 / 相册”双项毛玻璃胶囊；外层手势区高 `56dp` |
| 底部选中滑块 | `104 × 44dp` | 占据单个分段的乳白椭圆，左右各保留 `4dp` 呼吸空间 |

## Android 16 毛玻璃

- 实现入口：`ui/components/Android16Glass.kt`。
- 仅用于浅色悬浮表面；黑色新增按钮和蓝色主按钮保持实色，确保视觉层级清晰。
- 页面列表通过 `hazeSource` 进入可采样图层，玻璃表面通过 `hazeEffect` 对对应背景区域执行 `22dp–40dp` 空间模糊。
- 模糊结果叠加白色雾化、`6%` 细颗粒与高光边缘；底层照片只保留色相和大轮廓，细节不得清晰透出。
- 顶部到右下角使用方向性透光渐变；普通玻璃控件可绘制 `1dp` 白色高光，底部导航明确禁用边框。
- 底部导航雾化最强，搜索/筛选与时间选择器次之；选中项用高不透明乳白表面建立层次，不额外画描边。
- 底部导航只显示“所有照片 / 相册”，不放扫描、任务、筛选、布局或创作入口。它们不属于照片应用的一级信息架构。
- 外层是单一无描边长胶囊，内部选中态是占据半段的横向乳白椭圆。点击或水平拖动时以弹簧动画移动，文字字重同步变化。
- 胶囊使用 `52dp` 可见高度和 `224dp` 宽度，接近参考图的宽低比例；不得再次压成细线，也不得在两侧追加独立圆形按钮。
- 在纯白背景上仍要能看见轻微灰雾底色；移动到照片上方后应采样照片色相并模糊细节，不能退化成普通透明层。
- 玻璃必须能够反映背后照片的色相，但不得让文字、人物轮廓像普通透明层一样清晰透出。
- 禁止为 API 35 及以下提供降级色块，本项目不支持旧系统。

## 照片时间线尺寸

- 顶部内容从原生状态栏安全区下方 `20dp` 开始。
- 头像尺寸 `42dp`；搜索和筛选按钮 `52dp`；按钮间距 `10dp`。
- 顶部栏与标题间距 `16dp`。
- 页面标题为 `36sp / 42sp` 粗体；月份信息为 `17sp`。
- 时间选择器触控区域为 `144 × 48dp`，可见玻璃轨道高 `40dp`、内部滑块高 `36dp`；三个分段各有 `48dp` 触控宽度。
- 日期标题为 `24sp / 30sp` 粗体；地点为 `17sp` 灰色中等字重。
- 第一组照片三行高度依次为 `142dp`、`144dp`、`128dp`。
- 第二组照片预览行高度为 `170dp`。
- 列表底部至少预留 `116dp`，防止悬浮导航永久遮住照片。

## 合集页面尺寸

- 合集封面宽度跟随内容区，高度 `150dp`，外圆角 `28dp`。
- 封面下层半透明面板高度 `72dp`，顶部圆角 `24dp`。
- 卡片内新增按钮尺寸 `50dp`，距离右边 `18dp`。
- 封面与标题间距 `18dp`；合集之间的垂直节奏为 `32dp`。

## 图集详情页

- 顶部返回与设置只承担导航，不与标题挤在同一行；图集名称使用 `40sp / 46sp` 粗体，元信息降为 `15sp` 灰色文字。
- 路径相册默认只显示一条紧凑扫描工具栏。目录管理与扫描历史均按需展开，不能在照片前常驻大段后台管理卡片。
- 照片网格使用三列、`4dp` 间隙与 `12dp` 圆角，整个图片区保持连续，不再继承页面级 `18dp` 行距。
- 单张照片上不常驻菜单圆或其它组件。点击打开照片，长按才显示“设为封面 / 从图集中移除”等上下文操作。
- 扫描按钮和所有隐藏操作仍保留至少 `48dp` 的触控区域。

## 资产详情页

- 详情页采用与首页同源的浅色系统相册查看器：背景统一为 `#F7F8FA`，原图保持原比例完整显示，不使用黑色三段式结构、照片取色渐变或装饰性大胶囊。
- 顶部仅保留返回、来源目录或标题、拍摄时间和更多。来源使用 `15sp` 半粗体，日期使用 `12sp` 灰色；文件名、尺寸和路径不常驻主画布。
- 底部由连续的 Android 16 毛玻璃表面承载两层内容：`58dp` 真实缩略图胶片与 `62dp` 五等分操作栏。当前缩略图以尺寸和透明度差异选中，不添加硬描边。
- 高频动作固定为分享、收藏、照片信息、编辑、移入回收站，图标统一使用轻量线性样式并保留 `48dp` 触控区；标签、评分、归档、私密和回收站恢复等低频能力继续从“更多”进入。
- 从全部照片进入时，查看器接收当前已加载的真实资产快照；点击缩略图或左右滑可切换，不能复制当前图片伪造胶片。多张照片产生的变更在退出时合并后一次性刷新各消费者。
- 点击静态照片切换“控件显示 / 纯照片沉浸”，上滑打开照片信息，双指保留 `1–3×` 缩放。视频继续由 Media3 播放控件接管；动态照片的静态/动态切换保持可用。

## 无障碍约束

- 可交互区域不得小于 `48dp`；较小的成员头像只承担信息展示，不可点击。
- 每张时间线照片都必须在 `MockAlbumRepository` 中提供中文内容描述。
- 主文字与辅助文字在浅色背景上必须维持足够对比度。
- 浅色页面和资产详情页均使用深色系统图标；照片沉浸态只隐藏应用 chrome，不伪造或重绘 Android 系统栏。
- 纯装饰图片应将内容描述设为 `null`，避免屏幕阅读器重复播报。
